# fux scoreboard

The page that stood here was from 288ff60 (2026-10-04) and an older setup, so it is gone.

The scoreboard of the fux-vt-best pass, at its final commit beside checkpoint 0 and every engine, with its fairness records and raw results, is in the description of [PR #174](https://github.com/gold-silver-copper/fux/pull/174).

`fux-vt/compare/run.sh scoreboard` writes this page again, for the commit it runs at, from that run's results; `history.jsonl` keeps a line for each commit it was kept for.
